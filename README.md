# SignCrypt 🤟

AI-powered sign language and secure communication platform using
TensorFlow, OpenCV, Flutter, and Morse Code integration.

## Features
- Real-time ASL gesture recognition
- Morse code conversion
- Text-to-speech
- Encrypted communication
- Flutter mobile integration
- TensorFlow Lite deployment

## Architecture
Frontend: Flutter + Web UI  
Backend: Python + TensorFlow + OpenCV

- Frontend: https://github.com/Bobby-111/Frontend
