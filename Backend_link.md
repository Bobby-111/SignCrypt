# SignCrypt Backend

This repository contains the backend implementation of the SignCrypt platform.

## Backend Responsibilities
- Real-time ASL gesture recognition
- TensorFlow/TFLite model inference
- Morse code processing
- Grammar correction workflows
- Encryption and decryption logic
- API handling and backend services

## Technologies Used
- Python
- TensorFlow
- OpenCV
- Flask
- NumPy
